📡 التثبيت اللاسلكي (RPI)

ابعت أي ملف PKP للـ PS4 من الموبايل أو الكمبيوتر من غير فلاشة نهائيًا — الجهاز بينزّل اللعبة بنفسه من الإنترنت ويثبّتها. الخدمة مدمجة في GoldHEN وشغالة بعد الجيلبريك مباشرة

إيه الفكرة؟

بعد الجيلبريك، GoldHEN بيشغّل سيرفر تثبيت لاسلكي جوه جهازك على المنفذ 12800 (خاصية Remote Package Install الرسمية). أي جهاز تاني على نفس الواي فاي — موبايلك أو كمبيوترك — يقدر يبعتله لينك تحميل أي ملف PKG، والـ PS4 ينزّله ويثبّته لوحده لحد ما يخلص.

اللي بيوفره عليك: مفيش تنزيل على الكمبيوتر ونقل بفلاشة ومساحة على الديسك — اللعبة بتروح من مصدرها للـ PS4 مباشرة على أسرع مسار، وبتشوف التقدم على شاشة الـ PS4 نفسها لحظة بلحظة.

الصفحة دي بتشتغل من الموبايل — افتح هوسنا من موبايلك بعد ما تعمل جيلبريك للـ PS4، واملأ البيانات وابعت. (وتشتغل بعد كده أوفلاين — الصفحة بتتحفظ عندك تلقائيًا من أول زيارة).

المتطلبات (كلها مجانية)

1. جهاز PS4 مكسور:الجيلبريك شغال بـ GoldHEN من هوستنا — السيرفر بيبقى شغال طالما HEN في الذاكرة (من غير ريستارت).
2. نفس الشبكة:الموبايل/الكمبيوتر والـ PS4 واقفين على نفس الواي فاي/الراوتر.
3. لينك PKG مباشر:رابط تحميل مباشر لملف اللعبة يبدأ بـ http أو https وينتهي بـ .pkg.
4. رقم IP الجهاز:من إعدادات PS4 ← الشبكة ← عرض حالة الاتصال ← رقم IPv4 (زي 192.168.1.10).

١. ابعت الباكج ✉️

من: إعدادات PS4 ← الشبكة ← عرض حالة الاتصال ← IPv4

لازم رابط مباشر بيلعب ملف .pkg — مش صفحة تحميل

بعد الإرسال راقب شاشة الـ PS4 — التقدم بيظهر هناك. والموبايل تقدر تقفله عادي، التثبيت شغال على الجهاز.

٢. الخطوات الكاملة بالترتيب

  1. اعمل جيلبريك للـ PS4 من صفحة الهبوط — لحد ما GoldHEN يقولك إنه اتحمّل بنجاح (ده اللي بيفتح سيرفر التثبيت).
  2. هات رقم الـ IP: إعدادات PS4 ← الشبكة ← عرض حالة الاتصال — دوّن رقم IPv4.
  3. افتح الصفحة دي من موبايلك/كمبيوترك (نفس الواي فاي) — أو استمر من متصفح الـ PS4 نفسه مع زر 127.0.0.1.
  4. املأ الخانتين واضغط «ابعت للـ PS4» — هيظهرلك نتيجة الإرسال فورًا (تفاصيلها تحت).
  5. راقب شاشة الـ PS4 — هتبدأ اللعبة في التنزيل والتثبيت تلقائيًا، وبعد ما تخلص تلاقيها في قائمة المحتوى.

٣. إزاي تقرا نتيجة الإرسال؟

السيرفر بيرد برسالة JSON بسيطة — الشكل بتاعها ومعناها:

الرسالة اللي ظهرتلكمعناها
{ "status": "success" }✅ الإرسال تم! — التنزيل بدأ على الـ PS4، تابع الشاشة
{ "status": "fail", "error_code": 0x80990085 }❌ المساحة مش كافية — امسح ألعاب/ملفات وحرر مساحة وجرب تاني
{ "status": "fail", "error_code": ... }كود خطأ تاني — راجع جدول الحل تحت
الصفحة رفضت تتصل / Timeoutالسيرفر مش شغال — الجيلبريك وقع (اعملو تاني) أو الـ IP غلط أو مش نفس الشبكة

💡 الرسالة بتظهر في تاب جديد من متصفح الموبايل — لو ظهر فيها success خلاص، ارجع للصفحة واطفي التاب.

⚙️ التفاصيل التقنية (للمهتمين)

الأداة بتكلم واجهة الـ API الرسمية المدمجة في GoldHEN: POST http://<IP>:12800/api/install بجسم JSON بصيغة {"type":"direct","packages":["رابط-الـPKG"]} — نفس البروتوكول بالظبط اللي بستخدمه أدوات التثبيت المعروفة (زي DirectPackageInstaller).

لأن صفحتنا بتشتغل بـ HTTPS والسيرفر بتاع الجهاز HTTP (شبكة منزلية)، بيتم الإرسال بـ نموذج ملاحي مباشر من المتصفح — الطريقة دي بتعدّي تحظرات الحماية (Mixed Content) اللي بتوقف أدوات الإرسال العادية، من غير أي تنازل في الأمان (البيانات بتروح لجهازك انت جوه شبكتك). وفوق كده الأداة بتجرب الاتصال المباشر الأول لو المتصفح سامح.
